# TSD for lsFusion on Android

TSD — конфигурация на lsFusion для терминала сбора данных на Android. Проект реализует настройки локальной и основной базы, синхронизацию справочников, выбор типов документов и формы ввода штрихкодов для сценариев складского учёта.

## ✨ Особенности

- Конфигурация lsFusion для TSD-сценариев.
- Работа с локальной и основной базой через настраиваемые параметры подключения.
- Формы авторизации, выбора документов и ввода штрихкодов.
- Синхронизация справочников, пользователей, складов, ячеек и штрихкодов.
- Модули импорта из 1C и буферы обмена.
- Навигатор с формами документов и настроек.

## 🚀 Быстрый старт

Проект представляет собой набор `.lsf`-модулей для развёртывания в lsFusion. Сборочные скрипты в этом каталоге отсутствуют, поэтому старт зависит от вашей среды lsFusion.

Из исходников видно следующие опорные параметры:

- модуль входа: `src/main/lsfusion/Main.lsf`
- базовые настройки: `src/main/lsfusion/tsd/TsdConfig.lsf`
- адрес основной базы по умолчанию: `http://127.0.0.1:8080/server`

После публикации конфигурации в lsFusion используйте формы настроек и документов из навигатора `tsd`.

## 📁 Структура проекта

- `src/main/lsfusion/Main.lsf` — основной модуль и web/login hooks.
- `src/main/lsfusion/tsd/TsdConfig.lsf` — настройки TSD и синхронизация с основной базой.
- `src/main/lsfusion/tsd/TsdVars.lsf` — переменные и параметры конфигурации.
- `src/main/lsfusion/tsd/catalogs/` — справочники штрихкодов, ячеек, номенклатуры, единиц измерения, пользователей и складов.
- `src/main/lsfusion/tsd/doc/` — модели документов и типы операций.
- `src/main/lsfusion/tsd/inputForm/` — формы ввода и контроля сканирования.
- `src/main/lsfusion/tsd/login/` — форма логина оператора.
- `src/main/lsfusion/tsd/syncData/` — буферы синхронизации, импорт и экспорт.

## 🛠 Использование

Ключевой пользовательский поток в коде строится вокруг формы настроек `tsdConfig`, действия `syncClientWithMainBase`, списка документов `tsdListDoc` и форм ввода из `inputForm/`. Конфигурация рассчитана на работу терминала как клиента, который может синхронизироваться с основной базой и отправлять/получать данные по HTTP.
